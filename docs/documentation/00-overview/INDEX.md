# Overview

kol-chess is a web app built on Vite + React 19 + Tailwind v4 (pnpm, react-router-dom) and the KOL design system — a chess analysis board, a queryable game database, and a statistics dashboard over 27,200 chess.com games. This `INDEX.md` *is* the overview — the folder reserves the `00-` namespace and needs no loose siblings.

This is where a reader starts. From here: [[../01-architecture/INDEX|architecture]] for the app's shape, [[../02-data-pipeline/INDEX|data pipeline]] for where the games come from, [[../03-database/INDEX|database page]] and [[../04-theme/INDEX|theme]] for the deep dives, and the sibling [[../../operations/INDEX|operations/]] for how it builds and ships.
